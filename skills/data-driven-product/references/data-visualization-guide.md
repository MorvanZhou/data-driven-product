# Data Visualization Guide (ECharts + HTML)

## Core Principles

1. **Interactive charts**: All charts rendered with ECharts, supporting hover tooltips, zoom, and data linking
2. **Self-contained HTML**: Reports are single HTML files, loading ECharts via CDN, openable directly in a browser
3. **One chart, one insight**: Each chart conveys one clear conclusion; the title IS the insight (e.g., "Mobile bounce rate is 2x desktop")
4. **Embedded data**: Chart data embedded as JSON in HTML `<script>` tags

## ECharts CDN

```html
<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>
```

## Chart Type Selection

| Data Pattern | ECharts Chart Type | Use Case |
|-------------|-------------------|----------|
| **Time trends** | `line` | GSC click/impression trends, GA4 traffic trends, lifecycle assessment |
| **Category comparison** | `bar` (horizontal) | Top keywords, page rankings, channel comparison |
| **Proportion composition** | `pie` / `treemap` | Traffic source distribution, device share, need clustering |
| **Funnel conversion** | `funnel` | User conversion funnel, signup/purchase flow |
| **Dual-metric correlation** | `scatter` | CTR vs ranking, bounce rate vs load time |
| **Multi-dimensional comparison** | `radar` | Page health scores, channel ROI comparison |
| **Ranking + value** | `bar` (horizontal + value label) | Top 10 pages/keywords |
| **Heat distribution** | `heatmap` | Time-of-day traffic distribution, geo traffic heat |
| **Dashboard** | `gauge` | Performance scores, conversion rate goal achievement |
| **Comparison (before/after, expected vs actual)** | `bar` (grouped) | Pre/post optimization comparison, expected vs actual behavior |

## Chart Generation Pattern (Python Scripts)

Analysis scripts should include a `charts` field in their output JSON, where each element is an ECharts option object:

```python
import json

# Analysis result
analysis_result = {
    "summary": "Mobile bounce rate 72% is much higher than desktop 45%",
    "data": {...},
    "recommendations": [...],
    "charts": [
        {
            "id": "device_bounce_rate",
            "title": "Mobile bounce rate is 1.6x desktop",
            "option": {
                "tooltip": {"trigger": "axis"},
                "xAxis": {"type": "category", "data": ["Desktop", "Mobile", "Tablet"]},
                "yAxis": {"type": "value", "name": "Bounce Rate %"},
                "series": [{
                    "type": "bar",
                    "data": [45, 72, 58],
                    "itemStyle": {"color": "#4285F4"}
                }]
            }
        }
    ]
}

# Output
with open(output_path, "w") as f:
    json.dump(analysis_result, f, ensure_ascii=False, indent=2)
```

## Report Generation Script Pattern

The final report generation script reads all `$DATA_DIR/analysis/*.json` and assembles HTML:

```python
import json
import os

DATA_DIR = os.environ.get("DATA_DIR", ".skills-data/data-driven-product")
ANALYSIS_DIR = os.path.join(DATA_DIR, "analysis")
REPORTS_DIR = os.path.join(DATA_DIR, "reports")
os.makedirs(REPORTS_DIR, exist_ok=True)

# Read all analysis results
analyses = {}
for fname in os.listdir(ANALYSIS_DIR):
    if fname.endswith(".json"):
        with open(os.path.join(ANALYSIS_DIR, fname)) as f:
            analyses[fname.replace(".json", "")] = json.load(f)

# Collect all charts
all_charts = []
for name, data in analyses.items():
    if "charts" in data:
        all_charts.extend(data["charts"])

# Generate HTML (using Jinja2 or string concatenation)
html = generate_html(analyses, all_charts)

with open(os.path.join(REPORTS_DIR, "report.html"), "w", encoding="utf-8") as f:
    f.write(html)
```

## Chart Requirements by Analysis Module

### Pre-Analysis Charts

| Module | Required Charts |
|--------|----------------|
| P1 Market Demand | Keyword search volume trend (line), demand scale TAM (gauge/bar) |
| P2 Competitor Reverse-Engineering | Coverage gap word cloud/bar, opportunity priority scatter (scatter) |
| P3 Intent Gaps | Intent classification distribution (pie), gap opportunity ranking (bar) |
| P4 Opportunity Assessment | ROI scoring matrix (scatter: difficulty vs return) |
| P5 Need Clustering | Need group treemap, cluster size comparison (bar) |

### Post-Analysis Charts

| Module | Required Charts |
|--------|----------------|
| A1 Page Health | Page score ranking (bar), health radar (radar) |
| A2 User Paths | Path Sankey or flow diagram, engagement distribution (bar) |
| A3 Funnel Diagnosis | Conversion funnel (funnel), device comparison funnel (bar grouped) |
| A4 Channel ROI | Channel effectiveness comparison (bar), quality scatter (scatter: volume vs quality) |
| A5 Device/Geo | Device metric comparison (bar grouped), geo heat (map/heatmap) |
| A6 Content Decay | Declining page trends (line), change magnitude ranking (bar) |
| A7 Technical Health | Audit pass rate (gauge), issue distribution (pie/bar) |
| A8 User Personas | Population distribution (pie), behavior difference radar (radar) |

### Decision Analysis Charts

| Module | Required Charts |
|--------|----------------|
| D1 Lifecycle | 90-day trend (line) + phase annotations |
| D2 ROI Comparison | ROI comparison (bar grouped: optimize vs build new) |
| D3 Abandonment Signals | Signal dashboard (gauge), multi-signal scoring (radar) |
